| 球触骑跨中线裁判员 → 经 OBRI 30-10 原文判定「8 秒重新计算」 | 按原文定答案 |

## 二、搜索词优化（规则速查）

改动文件：`pages/index/index.js` / `index.wxml` / `index.wxss`

1. **同义词/别名映射表（30+ 组）**：口语说法自动扩展为规则术语再检索——
   走步↔带球走、打手↔非法用手、违体↔违反体育道德、加时↔决胜期、回场↔球回后场、干扰球↔干涉得分/干扰得分、发球/边线球/界外球↔掷球入界、换人/替补↔替换、24秒↔24秒钟/进攻计时钟/进攻时间、夺权↔取消比赛资格、技犯↔技术犯规 等。
   实测：搜「打手」精准命中第 33 条（非法用手）；搜「回场」命中第 28/30 条。
2. **搜索范围扩展到官方解释（OBRI）全文**：379 条官方规则解释纳入检索，命中正文无关键词但解释命中的条款会显示，并打上**「命中官方解释」**橙色小标签。实测：搜「跳球后」命中第 12/29 条（对应 OBRI 30-3 等案例）。
3. **命中上下文摘要**：卡片摘要由固定开头 42 字改为**关键词命中处前后截取**（前 20 后 44 字），一眼看到命中位置。
4. **热门搜索词**：未输入且未筛选时展示热搜行（带球走、干涉得分、球回后场、24秒、8秒、违体犯规、掷球入界、圆柱体、交替拥有、可纠正的失误），点按即搜。

## 三、裁判法优化（跨板块全局搜索）

改动文件：`pages/index/index.js` / `index.wxml` / `index.wxss`

- **原逻辑**：搜索只在「当前展开的板块」内过滤，搜「轮转」时若展开的是 M1 就什么都搜不到。
- **新逻辑**：关键词非空时自动切换为**全局搜索模式**——跨 M1-M4 全部板块（含 M2 术语表）检索，同义词表同样生效；结果**按板块分组**展示，带板块徽章（M1/M2/M3/M4）+ 组内命中数。
- 小节结果显示**命中上下文摘要**（如搜「追踪」直接看到该小节里含「追踪」的段落片段），术语词条直接全文展示，均可点击进详情。
- 搜索栏增加 ✕ 一键清空；清空后回到原「按板块折叠浏览」模式。
- 实测命中：「轮转」M1:1 M2:1 M3:4 M4:4；「追踪」M3:20 M4:20；「记录台」四个板块均有命中。
