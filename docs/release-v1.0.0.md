## 四、部署到生产（两种方法）

> 微信小程序的“生产环境”即微信公众平台。最终上线需经 **上传 → 提交审核 → 发布** 三步，平台审核约 1–7 个工作日。

### 方法 A：微信开发者工具（推荐首次发布）

1. 用**真实 AppID** 打开项目（`project.config.json` 已配 `wxb8e1708dd44558a2`）。
2. 菜单「工具 → 清除缓存 → 全部清除」→ 点「编译」。
3. 点右上角「**上传**」→ 版本号 `1.0.0`，备注如上 → 上传成功得到「开发版」。
4. 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) → **版本管理** → 开发版「提交审核」。
5. 审核通过后点「**发布**」→ 正式上线（用户即见）。

### 方法 B：miniprogram-ci 命令行（CI / 可复用自动化）

已备好 `scripts/upload-ci.js`：
```bash
cd scripts
npm i miniprogram-ci            # 依赖装到隔离目录，不污染全局
# 把上传密钥保存为 scripts/private.key（密钥本身已被 .gitignore 排除，切勿提交）
node upload-ci.js               # 自动取 config.js 版本号上传
```
上传密钥获取：mp.weixin.qq.com → 开发 → 开发管理 → 开发设置 →「上传代码」→ 生成/下载。

> ⚠️ 实际“按上传按钮”这一步必须由**持有密钥/账号的人**执行——我无法在微信服务器上替你操作，但已把可复用的部署路径准备好了。

## 六、回滚方案

| 场景 | 操作 |
|---|---|
| 审核中发现问题 | 直接不点「发布」即可，开发版不影响线上用户 |
| 已发布需回滚 | mp.weixin.qq.com → **版本管理** → 找到上一个「线上版本」→「回退」；或重新上传 `v1.0.0` 冻结包并提交发布 |
| 代码级回滚 | `git checkout v1.0.0` 或 `git revert` 到 `0abd9d4`，重新走上传流程 |
| 紧急停服 | 版本管理 →「暂停服务」（仅限特定类目，裁判工具类一般可用） |

> 建议：发布前在「版本管理」保留**上一个稳定版本**记录，作为一键回退锚点。
