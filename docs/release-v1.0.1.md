# Claw v1.0.1 发布说明

**发布代号**：规则文本排序与 OCR 清洗修复
**上一版本**：v1.0.0（2026-08-16 生产冻结）
**版本类型**：修订版（hotfix / 数据清洗）

## 背景

v1.0.0 真机体验后反馈两类问题：
1. **规则文本排序有问题** —— 部分条款的子条款编号被 OCR 误识，导致编号序列出现「跳号 / 倒序 / 重复」，看起来像排序错乱。
2. **有些位置清洗不到位** —— 部分条款正文仍残留 OCR 噪声（误插的数字、错字）。

## 改动范围

仅修改数据层 `data/rules.js`，**未改动任何页面/逻辑代码、未改动数据结构**，因此无需重新过审页面逻辑，回归风险低。

## 验证

- `node --check data/rules.js` 通过（语法有效）。
- `node check.js` 全部自检通过（exit 0），规则总数 50、标签、OBRI 关联未变。
- 子条款编号扫描：第 2/4/12/37/39/44 条恢复为严格递增序列；其余残留告警均为合法数字（`7.10`、`17.2.10`、`33.10-33.16`、`46.10-46.14` 等）或计量单位（`1.3 米`、`0.90 米`），非缺陷。

## 已知遗留（本次未处理，待公开前人工校对轮次）

- `data/mechanics.js` 同批 OCR 来源，存在少量疑似噪声（如 `视野2中`、`前导2裁判`、`追2踪裁判`、`犯规的类3型`），但其中大量数字为合法裁判术语（2/3 区、手指信号 1-8、轮转阶段数等），需人工逐项判别，故未在本修订版批量改动，避免误伤。可单独安排一轮 mechanics 校对。
- `data/interpretations.js` 扫描命中均为合法 `1次`（一次），无需修改。
