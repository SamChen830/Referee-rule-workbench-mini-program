## 四、如实说明的取舍

1. **数据管理**：按你的要求已**删除导出功能**，仅保留"重置答题统计"；数据全部存本机。
2. **解释折叠**：第 17 条有 52 条解释，默认只显示前 4 条 + "展开全部"按钮，避免长列表刷屏。
3. **手势节**：已隐藏但数据仍在 `data/mechanics.js`（约 8KB），需要时恢复一行代码。
4. **答题引擎**：题目随机乱序、即答即判、错题自动收录、错题重练答对即移出——逻辑沿用 v1 已验证的实现。

## 四·补 滑动/滚动交互优化（2026-08-16 追加）

| 问题（优化前）                                              | 优化后                                        |
| ---------------------------------------------------- | ------------------------------------------ |
| 切换模式后页面停留在上一个模式的滚动位置，悬在半空                            | 切模式自动回到顶部（瞬时，不拖泥带水）                        |
| 63 个标签横滚，选靠后的标签不知道自己选了哪个                             | 选中章节/标签**自动滚入视野**（scroll-into-view + 平滑动画） |
| 规则列表滚到下半段后，搜索栏和筛选够不着                                 | 搜索栏 + 章节/标签筛选**吸顶**（sticky），随手可换条件         |
| 长列表（50 条规则、错题本）滚到底没有快速返回手段                           | 右下角**回到顶部**悬浮按钮（滚动超一屏才出现，规则详情页同款）          |
| 所有可点卡片（规则卡/裁判法小节/分类入口/筛选 chip）无按压反馈                  | 统一加 hover 按压反馈（微缩放 + 变色，60ms）              |
| 答题点"下一题"后停留在上一题解析的滚动位置                               | 换题/查看结果/再来一轮均**自动回顶**                      |
| 确认答案后解析可能在屏幕外看不到                                     | 确认后**自动滚到解析区**（平滑动画，低版本基础库静默降级）            |
| 答题选项已判分后仍可按出按压反馈，像还能改答案                              | 判分后选项按压反馈禁用                                |
| **Bug**：结果页正确率用 WXML 写 `Math.round()`（WXML 不支持），显示空白 | 正确率改 JS 预计算 `resultPercent`                |

> 未做"左右滑动切换模式"：与筛选标签的横向滚动手势冲突，容易误触，判断为不合理交互，主动放弃。
