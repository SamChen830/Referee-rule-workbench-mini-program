## 保留规则

1. 上一段末是强标点（。！？；：）)” 等）→ 保留
2. 下一段以带点条款号开头（`1.1` / `25.1.1` / `2.3`）→ 保留
3. 下一段以章节关键词开头（定义/解释/注/示例/条文/说明/——）→ 保留
4. 上一段是「短标题」（带点条款号+短标题，无句末标点，如 `2.3 后场`）→ 保留
