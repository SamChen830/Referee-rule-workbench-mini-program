## 〇、先要拍板的一个问题：Web 版和小程序是什么关系？

| 方案 | 说明 | 建议 |
|------|------|------|
| **A. Web 版替代小程序** | 放弃微信小程序，直接做响应式 Web App（手机浏览器体验也好） | 推荐：开发快、预览直观、随时改 UI |
| B. Web 版做 UI 原型 | 先在 Web 上把设计调到你满意，再移植回小程序 | 稳妥但多一轮移植成本 |
| C. 双端并行 | 同一套数据，两端同时维护 | 工作量翻倍，不推荐 |

**默认按 A 执行**（下文均以 A 为准），你若选 B/C 请指出。

## 一、技术栈（专家默认 + 项目适配）

| 层 | 选型 | 理由 |
|----|------|------|
| 框架 | **Next.js 15（App Router）+ React 19 + TypeScript strict** | 生产级、静态导出可部署任意平台 |
| 样式 | **Tailwind CSS v4** | 与设计 token 一一对应，改主题零成本 |
| 组件 | **shadcn/ui**（Button/Dialog/Tabs/Command/Badge/Sheet） | 不重复造轮子 |
| 图标 | **Lucide Icons** | 现代感、统一线宽 |
| 状态/存储 | React 状态 + **localStorage**（答题记录/错题本/导出 JSON） | 与小程序 wx.setStorageSync 同构，将来可平滑移植 |
| 部署 | 静态导出，Vercel / Netlify 一键上线 | 手机随时访问 |

## 二、设计系统（Design Tokens）

沿用你截图中的 **FIBA 绿工作台**风格：

| Token | 值 | 用途 |
|-------|-----|------|
| `--primary` | `#0F6E56`（深绿） | 品牌色、激活态、主按钮 |
| `--primary-bg` | `#E1F5EE`（浅绿底） | 激活标签、高亮行 |
| `--primary-text` | `#085041` | 绿底上的文字 |
| 强调-错题 | `#993C1D`（赭红） | 错题数、答错反馈（注意：**答题对错反馈遵守中国习惯之外的教育惯例——答错用红、答对用绿**） |
| 中性色 | Tailwind zinc 灰阶 | 文字/边框/背景 |
| 字体 | 中文系统栈（PingFang SC / 微软雅黑）+ 数字 `tabular-nums` | 统计数字对齐 |
| 圆角 | 卡片 12px、标签/按钮 999px（胶囊） | 与截图一致 |
| 间距 | 8pt 网格 | 节奏统一 |
| 深色模式 | 内置 light/dark 切换，跟随系统 + 手动覆盖 | 默认提供 |

## 三、信息架构（单页工作台，无 tabBar）

参照截图风格，**一个页面承载三大模式**，顶部胶囊切换（替代小程序 tabBar）：

```
┌─ FIBA 规则裁判员工作台 ──── [规则速查|裁判法|答题] ─┐
│  统计卡：已练习 / 正确率 / 连对 / 错题本待清          │
│  ── 模式一：规则速查 ─────────────────────          │
│    搜索框（支持条款号/关键词/标签，⌘K 唤起）           │
│    章节折叠列表 + 标签筛选（违例/犯规/3秒钟/球回后场…）│
│    条款卡片 → 点击展开详情（子条款全展开 + 关联标签）  │
│  ── 模式二：裁判法 ─────────────────────            │
│    四大板块卡片：2人执裁 / 个人执裁技术(IOT)          │
│                 / 3人执裁基础 / 3人执裁进阶           │
│    板块内按小节速查（轮转、区域分工、罚球管理…）       │
│  ── 模式三：答题 ───────────────────────            │
│    按标签出题（对齐条款号）· 情景题（取自规则解释V3.0）│
│    即时判分 + 解析回链条款 · 错题重练模式             │
└─ 底部工具条：导出JSON备份 / 重置统计 / 主题切换 ──┘
```

**页面路由**（3 个路由，其余全组件化）：

| 路由 | 内容 |
|------|------|
| `/` | 工作台（三模式切换、统计、设置） |
| `/rule/[id]` | 条款详情页（分享/收藏友好的独立 URL） |
| `/practice` | 沉浸答题页（全屏、进度条、键盘 1-4 选答） |

## 四、关键交互与状态

- **三态全覆盖**：每个数据区都有 loading（骨架屏）/ error / empty 状态，不做"能跑就行"版
- **搜索**：`cmdk` 命令面板，支持"第26条""3秒""干涉得分"混合检索
- **答题反馈**：选中即判——答对绿描边、答错红描边并展示正确项 + 解析 + 「查看条款」跳转
- **错题本**：答错自动收录，重练答对自动移出，与小程序版逻辑一致
- **导出/重置**：导出完整 JSON（统计+错题+刷题记录），重置需二次确认 Dialog
- **a11y**：语义化标签、键盘可完成整套答题流程、对比度 AA
- **mobile-first**：单列布局起步，`md:` 断点起规则列表变双栏
