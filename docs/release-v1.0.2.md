## 本次修正内容

### 1. 数值错乱（第 2.2 节「距离和静立占位」）
- 原文 `完全的 26名队员中的36名队员（722%）` 为明显的 OCR 数字错位。
- 依据邻近第 2.5 节确认分母恒为 **36**（`36名队员中的32名（89%）`），故修正为：
  `全部的36名队员中的26名队员（72%）`（26/36 ≈ 72%）。
- 同段顺带清理：`排名队员` → `排的队员`（×3）、残留破折号 `-等` → `等`、`完全的` → `全部的`。

### 2. 术语表（M2）缩写与名称纠错
- `前导裁判` 缩写 `年`（OCR 杂入）→ **`L`**（Lead）。
- `追踪裁判` 缩写为空 → **`T`**（Trail）。
- 术语名称中混入的空格/多余数字修复：
  - `人执裁`（3PO / 2PO）→ `3人执裁` / `2人执裁`
  - `制造 （投篮动作）` → `制造（投篮动作）`
  - `明显的情况 2` → `明显的情况`
  - `外向内观察 （角度）` → `外向内观察（角度）`
  - `详细陈述 3` → `详细陈述`
  - `强侧 （执裁/3人执裁）` → `强侧（执裁/3人执裁）`
  - `违反体育运动 精神的行为 （行为）` → `违反体育运动精神的行为（行为）`

### 3. 第 2.8 节「轮转」（M4 高级轮转）
- 阶段数 `轮转有4个不同的阶段` → `轮转有3个不同的阶段`，与 M3 一致（失衡情况为补充情形，并非独立阶段）。
- 清理杂散字符：`K3人执裁` → `3人执裁`、步骤 2 中多余前导 `.`、图注前多余 `3 图25`、以及 `轮转 完成` 间多余空格。

### 4. 残留空括号
- 全文 `裁判（）` 空括号（OCR 杂入）清理：第 2.5 节 `前导裁判（）和追踪裁判（）` → `前导裁判和追踪裁判`；第 M4 节 `追踪裁判（）、前导裁判（）、中央裁判（）` → `追踪裁判、前导裁判、中央裁判`。共 5 处。
